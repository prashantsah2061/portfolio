PyTorch LSTM NLTK

Next Word Predictor

LSTM-based next-word prediction model built from scratch in PyTorch using an embedding → LSTM → linear architecture. Full NLP pipeline: NLTK tokenization, 249-token vocabulary, 631 sequences, padded batching (max length: 127). Trained 50 epochs with Adam + cross-entropy loss — hit 99.52% accuracy with final loss of 1.35. Supports both single-step and iterative autocomplete-style generation.
